# Friday Niite Freestyle → Psych Engine

This is the start of the conversion of your Freestyle mod to Psych Engine 0.7.2h.

## What is already done
- `pack.json` created
- Chart files will be placed in `data/`
- Basic structure ready

## What YOU still need to do (important)

1. **Copy the audio files**
   From `freestyle-html/assets/songs/`  
   → copy the entire folder into  
   `Psych-0.7.2h-code/mods/Freestyle/songs/`

2. **Copy images / characters / stages**
   From `freestyle-html/assets/` (images, shared, etc.)  
   → put the relevant folders into  
   `mods/Freestyle/images/`, `characters/`, `stages/` as needed.

3. After copying, the mod should appear in the engine.

## Songs included
Doobop, Refreshed, Spooky Fight, Creepz, North, Night Lights, Gunfight, Funky Nice, Turf War, Ecstacy, Cruise Control, Joyride, Slurry, Flurry, Snowblind, Social Suicide, Recess, Splinters

You can keep adding more charts by placing them in `data/songname/songname.json`.
